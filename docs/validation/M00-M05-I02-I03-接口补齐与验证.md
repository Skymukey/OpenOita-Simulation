## 冻结接口

原IPreparedMutation增加编辑后的只读租约：

```csharp
ITickInstanceMap CandidateInstances { get; }
ReadOnlySpan<CellPositionKey> CandidateWrites { get; }
```

原IMaterialMutationPreparer只保留以下唯一签名，全部已有消费者同步更新：

```csharp
PreparationResult<IPreparedMaterialMutation> Prepare(
    IPreparedMutation candidate, StructurePlan structure,
    BodyIdReservation reserveBodyIds, ITickChangeCounter changes,
    MaterialOwnershipPreparation prepareOwnership,
    in TransactionContext context, IFailureInjector failures);
```

MaterialOwnershipPreparation绑定M02当前候选，输入既有PlannedCell、BodyIdMapping、BodyGeometryPlan、新IMaterialBodyStorage及撤销BodyId清单。体存储提供只读Snapshot、Geometry、OccupiedPositions、TryRead及幂等Dispose，不暴露可写CellState数组。

成功时全部结果合入原编辑候选并接管存储，返回**同一个**IPreparedMaterialMutation；协调器不能重复Own。失败时M05释放未移交存储，M02撤销整个编辑候选。M05只计算，不直接修改实例表、计数器、世界或发布版本。

## 实际实现与提交边界

| 文件（相对仓库根目录） | 行为 |
| --- | --- |
| Assets/Scripts/OpenOitaWorld/Core/Contracts/TransactionContracts.cs、WorldViews.cs | 冻结候选租约、受控归属回调与材料体存储所有权；无旧Prepare重载或平行世界入口。 |
| Assets/Scripts/OpenOitaWorld/Simulation/WorkingWorld.cs、WorkingWorldOwnership.cs | Tick0真实候选、材料体目录/局部格读取、归属预检及一次采用；删空旧体保留到结构分析完成。 |
| Assets/Scripts/OpenOitaWorld/Simulation/TickChangeCounter.cs | 在准备阶段构建原编辑与转移源/目标键的整Tick集合，合并后Budget给出准确数；Apply采用集合而不逐项分配/Record。 |
| Assets/Scripts/OpenOitaWorld/Simulation/CommittedWorldView.cs | 独立复制体快照与全部材料状态；工作采用前后旧公开副本保持原版本。 |
| Assets/Scripts/OpenOitaWorld/Structure/MaterialMutationPreparer.cs、BodyExtractionPlan.cs | 公共适配器复用既有提取/矩形/质量计算；成功受控准备后计算计划放弃体存储所有权。 |
| Assets/Scripts/OpenOitaWorld/Simulation/Bodies/MaterialBody.cs | 既有唯一局部CellState存储实现IMaterialBodyStorage，只读查询、幂等释放。 |

CandidateInstances是查询门面，拒绝Create/Move/Invalidate/MarkWet。Spawn读取新候选句柄；Move沿用原实例及湿标记；同ID Replace仍生成新干实例并撤销旧固定约束。Apply、Abort、Dispose、故障、错线程或修订失效后租约不可读，旧代次查询返回false/default。

受控归属预检校验完整源状态/实例、源目标唯一性、全部结构覆盖、D03顺序、当前候选预留ID、撤销清单、完整旧新映射、真实矩形覆盖、体存储/位姿/版本及完整预算。准备阶段不改工作状态。全部参与者预检成功后，同一次Apply采用网格移出、固定/占据、体存储/快照、实例/湿集合、整Tick计数与修订；发布由M02单独完成。

存储准备成功后归M02候选所有；Abort释放未采用存储，Apply移交世界并释放旧体，之后准备对象Dispose不释放已采用存储，世界Dispose负责最终释放。预检失败保持原格/体/实例/计数和公开副本；命令可拒绝，规则准备失败进入Faulted并冻结公开版本。Apply后异常不宣称物理回滚。
