## 规则与合同变更

[公共合同 1.7](../specs/CONTRACTS.md#d04-的液体平衡与原子链17)和 [M03-L01](../specs/M03-L01-液体扩散与液面平衡.md)明确了占据目标的唯一例外：完整原子链中的下一份同材水在同批离开，链尾必须进入快照空位，且比链首低。每份水只沿下/左/右走一格，整条链同时提交；不增加压力、上移、瞬移或单实例多步。

自由表面按 y 降序、x 升序选择，BFS 在可移动同材水中寻找最低原空终点，再按最短路径及稳定邻接顺序裁决。所有链节点先预留，余下水执行下落、合法斜下和有低处依据的水平一步。无下降出口的平衡水层停止搬运。失败搜索结果只在本阶段内复用，下一阶段从快照重建。

M02 先检查唯一源/目标、同材、正交、净下降和原空终点，再在候选副本内从链尾迁移实例。中间格接收前驱完整状态，即使字节相同仍按实例变更计数。预览先清全部源再填全部目标；失败不发布半批。蒸汽五层规则、燃烧/灭火规则、JSON 字段、默认世界及移动间隔没有调整。

## 预算与剩余验收

新增搜索存储预留为 `88N+256` 字节：六个 int[N] 数组及水阶段预留集合从 N 扩为 2N 的保守余量。N=65536 时新增约 5.500 MiB；整个 RuleExecutionTable 的估算预留为 223875328 字节，约 213.504 MiB。这是预算估算，不是峰值内存测量。当前没有调用者把 `ReservedCpuBytes` 合并到整个世界资源预算；默认状态容量与变更缓冲的部分预留已至少52 MiB，加规则估算即超过256 MiB。正式世界集成前需要合并并缩减预算，不能据此声称完整模拟满足256 MiB。

稳定连通水体的失败 BFS 在单阶段复用；一般最坏工作量仍随自由表面数 S、材料容量 N 和世界宽高 W/H 增长，约 O(SN + NWH)。本轮收敛 Tick 与 NUnit 墙钟不是 P2 完整 Step 耗时。现有规则GC测试的正对照失败（.NET计数0字节，Profiler为200字节，未可靠检测8192字节分配），因此明确忽略1项，不能报告零GC。完整 P2 的 p95/p99、可靠 GC Alloc 和 Windows 非 Development Player 测量仍待完成；不能以编译、探针或 Editor 功能通过替代。
