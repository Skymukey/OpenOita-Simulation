## 调用与拥有权

```csharp
// M02 调度器内部：writes 是已完成竞争裁决的整批写入。
var preparation = working.Prepare(writes, context);
// 先检查 preparation.Result；失败按阶段处理，不继续消费句柄。
var structure = working.PlanStructure(preparation.Prepared, planner, context, failures);
// 成功后，M05 在同一 Prepared 租约消费 CandidateWorld + structure.Plan；M06 继续准备。
// 所有参与者交给既有 TransactionCoordinator 预检；全部成功后 Apply。
// 自动阶段协调器 RequiresFault 时，M02 必须调用 working.Fault()；完整 Tick 后才能 Publish。
```

初态使用 PlanInitialStructure(planner) 全量扫描；这只是状态核心入口，正式 Create 仍须等待所有后续服务成功。CandidateWorld 是准备对象拥有的租约，不是提交快照；消费者不可延长租约或写入候选。纯物理等无材料候选的参与者返回 null。返回的只读 Span 必须在有效租约内使用。

动态体候选目录必须包含待删空的原体，直到 M04/M05 消费完成。当前 WorkingWorld 仅有网格、Bodies 为空；动态撤销/拆分分类由 M04 只读体夹具验证，未冒充真实体存储接入。

预算：非固定结果分量全部计入候选 DynamicBodies，包括保留旧体与新体；M04 不裁剪超限结果。现有 CPU 估计把按 maxMaterialCells 预留的结构扫描/计划复制工作集提高至每格640字节，覆盖本轮新增租约键和复制峰值的保守预留；M05/M06 的几何、实例迁移、形状和各自 CPU 仍须报告完整候选预算。这是估计口径，未实测全系统256MiB或稳态 GC=0。
