# 临时禁止刚体旋转：实现与验证

日期：2026年10月6日。目的：临时停止刚体旋转，保留下落、平移、碰撞、燃烧、拆分和查询，便于观察影响；保留恢复原行为的入口。

## 实现范围

- `WorldHost`和`SceneMaterialEditorWindow`提供默认开启的中文开关；`SampleScene`明确保存开启状态。
- `SceneEditorSession.BeginTrial`接收开关，默认开启。`WorldSimulation → SimulationWorld → WorldRuntime → WorldPhysicsAdapter`逐级传递创建参数，Reset沿用。
- `WorldPhysicsAdapter`统一恢复运动和旋转约束，覆盖准备、应用、内部同步；约束只冻结旋转。禁转几何计划和测试状态注入拒绝非零角速度。
- 通用工厂参数默认`false`以保留原程序化接入与旋转测试；用户可见的Host与试玩入口显式开启。不修改JSON格式、材料参数、显示角度、查询几何或全局物理设置。
- 新增`RotationConstraintTests`：偏心冲量开关对照、偏心支撑碰撞、燃尽/删除拆分、保留BodyId重建、Reset、默认Host、编辑器试玩两种模式。

## 验证结果

- Unity 6000.3.11f1脚本编译完成，无编译错误。
- Editor非batchmode的PlayMode全量 **80/80通过，0失败、0忽略**，包含新增9项禁转验证及原有71项物理、查询、显示和M08联验。运行器报告测试耗时7.56秒，这不是游戏性能测量。原始摘要见[PlayMode结果](临时禁转-PlayMode结果.json)。
- 新增验证覆盖：相同偏心冲量下禁转体仅平移、允许旋转体实际转动；木梁下落并停在偏心支撑上，30 Tick未旋转或穿透；燃尽/删除中格后两个子体保持禁转且继续下落；删除端格保留BodyId重建及Reset均保留约束；默认Host开启、编辑器默认开启与显式关闭均生效。
- 初次定向运行8/9通过：Host用例错误假设当前StreamingAssets初态已存在自由体，实际为0；改用明确的自由木梁三文本测试输入，最终全量通过。生产实现没有因此更改。
- 首次全量运行因Unity Test Framework在域重载期间抛出`PlayModeRunTask`空引用而中断，仅完成1项；编辑器恢复后重跑，得到上述80/80完整结果。未将中断运行计作成功。
- 本轮未另跑EditMode全量，未重新构建Windows Player，未测性能收益或长运行稳定性。

## 使用与边界

正式场景：停止Play Mode，在WorldHost的Inspector调整“禁止刚体旋转（重新启动生效）”，再运行。编辑器：退出试玩，调整“禁止刚体旋转”，再开始。Reset不切换模式，沿用创建时的设置。

此模式改变碰撞响应和接触时机，梁可能保持水平停在偏心支撑上；不是像素栅格化方案，连续平移仍存在。没有移除原旋转能力，不以禁转测试替代原旋转验收，也不承诺修复既有水汽排开故障。Windows Player未重新构建，已生成的可执行文件不会自动包含本轮改动。
