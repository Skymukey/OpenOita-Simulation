## 已冻结的签名

```csharp
// ITickInstanceMap
bool TryGetInstance(in CellKey key, out CellInstanceHandle instance);

// IRuleExecutor
IRuleBatch Execute(IWorkingWorldView snapshot, IMaterialRuntimeTable materials,
    ITickInstanceMap instances, IContactQuery contacts, in TransactionContext context);
```

TryGetInstance只查询当前Tick已登记实例，不创建实例、推进序号或修改湿集合；缺失位置、错误generation或关闭租约返回false/default。移到新位置后返回原句柄，旧位置失效；Remove使实例失效，Replace即使同材料ID也生成新句柄。实例表由M02持有，候选准备不外泄，事务应用时本Tick的实例表对象保持稳定。

Execute的instances参数是必需输入，位于materials之后、contacts之前，删除旧签名且不保留兼容重载。规则仅查询TryGetInstance/TryResolve/IsWet，输出引用当前实例的MutationIntent；Create/Move/Invalidate/MarkWet仍归M02受控阶段。调用方须保证阶段快照、实例表和TransactionContext的generation/workingTick一致；已占据源查不到当前句柄时规则返回失败批次，不使用default句柄或自行创建实例。
