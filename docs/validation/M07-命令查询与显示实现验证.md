# M07A/M07B 命令、查询与正式显示

日期：2026年10月6日（北京时间）。Unity 6000.3.11f1，公共合同1.9。开发前检查了git status，保留M00–M06既有改动；没有删除、提交或推送。测试入口使用正式`WorldSimulation/SimulationWorld/WorldRuntime`，不是M05Preview。

## 实现与模块归属

- M07A：`Commands/CommandQueue`提供4096待执行、最近4096结果及不透明World令牌；队列满不消耗序号。`MaterialCommandPlanner`复用M06几何及M02事务，整条命令预检，动态体替换液体/气体整拒。`Queries/QueryService`使用按材料上限预留的查询缓冲；缓冲不足不写任何部分结果，零长线段按真实半开格面返回全部命中。点/区域/线段分别遵守D05/D06。
- M00：在原`IWorldRenderer`旁补充`ITransactionalWorldRenderer/IPreparedWorldDisplay`，保留M06观察器兼容；生产默认显示使用事务接口。`FailurePoint`末尾追加`AfterDisplayTilePrepared`，不改变旧枚举值。
- M02：在物理和规则全部成功后，先构建下一版独立只读快照及完整ChangeSet，再准备显示资源；任何准备失败均不采用、不发布。准备完成后采用快照和显示，发布结果与通知，帧末上传。结果及ChangeSet租约分别在下次Step/Reset和回调结束时失效。执行阶段阻断读取/入队/重入，成功通知允许读取/入队，后者下一步执行。
- M07B：`Render/CommittedWorldRenderer`按主网格或BodyId的128×128局部块建立Point纹理，一格一原始纹素，不按最大材料ID建立切片。主网格采用origin/cellSize，动态体保持提交的连续位姿及几何原点。颜色亮度为`0.35+0.65×剩余燃料比例`；完整格占据、质量及碰撞完全由模拟决定。每块一批火焰四边形，共用火焰材质和Unity时间动画；Faulted时动画可以继续，但材料、位姿和火焰集合保留最后成功版。
- M02 Host接线：默认工厂创建生产显示；SampleScene保留既有资产GUID，显式引用材料/火焰Shader以进入构建依赖。默认像素视图为1:1，提供3倍按钮和整数格平移；窗口不足时裁剪，摄像机配置不改变世界状态。M08编辑工具接线仍不在本轮实现范围。
- M06联验修复：SAT以`(cosθ,sinθ)`和`(-sinθ,cosθ)`生成正交轴，消除`cos(π/2)`残差造成的静态共边伪重叠。严格正面积阈值仍为`>0`，Spawn和排开没有新增容差。世界查询上界保存为可表示Vector2，避免Mono扩展精度误拒129格尾块。

## ChangeSet与资源责任

ChangeSet表示上次成功版到本次成功版的净材料/实例变化，并包含整个Tick去重写入位置的脏范围；同位置反复修改合并，帧间没有可见净变化的位置仍可出现在脏范围中。完整字段包括格前后状态和键、生成/移除/燃尽/自然消散/替换/转移原因、体创建/撤销/旧新映射、主网格和体脏范围。原Tick实例跟随搬运和拆分；Replace即使同ID同状态仍可观测，且在随后提取时保留替换语义。保留BodyId但几何版本变化提供同ID映射。纯连续位姿不增加逐格写入数，但会使体显示范围刷新。

显示准备只写后台缓冲，新的Unity对象保持不可见；准备失败释放新增纹理、材质、网格和对象。采用只移交已准备字典和缓存，不分配或上传。多个成功Step累积纹理/火焰/位姿脏标记，帧末仅上传最终版本；空块和撤销体停用并释放。上传复用Color32缓冲及火焰工作列表，没有每次新建uint[]或逐格GameObject。

| 资源 | 唯一拥有者与释放 |
| --- | --- |
| 规则/状态、已提交快照、命令/查询缓存、ChangeSet | M02；Reset/Dispose清理租约，M07A缓冲计入统一CPU预算 |
| 体材料及几何、独立物理场景 | 复用M05/M06原所有权，正式世界释放 |
| 每块Texture2D、材料Material、火焰Mesh、显示对象 | M07B Tile；候选失败、空块、撤销或Dispose释放 |
| 共享材料四边形Mesh、火焰Material、显示根及帧末驱动 | M07B renderer；只释放一次，立即停用后允许Unity跨帧销毁 |
| 旧Render/WorldRender、图集和Compute原型 | 保留源码，没有接入生产Host；旧按ID切片路径不作为M07B实现或验收 |

Reset先清理旧模拟，再准备新显示；失败进入Faulted，保留旧显示，不暴露半新版本；成功才停用旧显示。Dispose可重复调用，不依赖外部逐项清理。

## 执行与结果

测试数据及失败修复记录保存在[M07证据目录](M07/)。首次把正式物理集成测试放入EditMode，10项因Unity禁止该模式创建运行时独立场景而失败；现已将正式集成测试迁至PlayMode，EditMode保留纯队列/查询核心。这个失败不算功能通过。

首次M07专属PlayMode为21/23；失败分别是缺少固定点导致自动提取（夹具错误）和129格上界比较精度（生产缺陷）。第一次全量PlayMode为59/61；失败分别是1格高世界中自由固体受到上下边界求解后超出M06误差预算，以及默认场景静态共边被SAT误判重叠。尾块用水验证主网格显示，独立物理故障不以放宽误差掩盖；SAT生产缺陷按上述方式修复并新增回归。最终结果见后续本节及JSON，不用初跑结果冒充全绿。

最终全量PlayMode **64/64通过，0失败、0忽略**，其中M07新增33项正式功能用例全部通过，原M06的28项继续通过；既有独立预览像素测试也通过，但不计作正式显示证据。[完整结果](M07/playmode-final.json)、[中文运行元数据](M07-测试结果.json)。EditMode全量502项，501通过、0失败、1忽略（既有GC计数器）；最后补充查询缓冲释放后受影响3项再次全部通过，去重覆盖仍为502项。这是全量和受影响范围复跑合并证据，不冒称又一次单次全量。见[全量JSON](M07/editmode-final.json)、[全量XML](M07/editmode-final.xml)、[释放回归](M07/editmode-dispose-regression.json)、[PlayMode XML](M07/playmode-final.xml)。

## 公开API使用与租约示例

```csharp
// Create和Step在Unity PlayMode/Player主线程执行；三份文本沿用严格加载合同。
var created = new WorldSimulation().Create(sources, origin);
if (!created.Result.IsSuccess) return;
IWorld world = created.World;
var queued = world.Enqueue(new MaterialCommand(MaterialOperation.Ignite, region, 0, world.Version.Generation));
// 此时仅入队；Retry是读取，不会重新执行。
CommandResult pending = world.Retry(queued.Token);
StepResult step = world.Step();
var savedResults = new CommandResult[step.Commands.Count];
step.Commands.CopyTo(savedResults); // 长期保存必须复制值。
var hits = new CellHit[128];
QueryResult selected = world.QueryRegion(region, hits);
// BufferTooSmall时按RequiredCount提供完整缓冲后重新查询，不消费部分内容。
world.Committed += changes =>
{
    CellChange[] savedCells = changes.Changes.Cells.ToArray();
    BodyIdMapping[] savedMappings = changes.Changes.BodyMappings.ToArray();
    // 不能保留changes.Changes供回调之后使用；其他目录/脏范围同样逐项复制。
};
world.Reset();
world.Dispose();
```

| Retry条件 | 结果 |
| --- | --- |
| 本World本代次且仍排队 | Pending |
| 完整成功Tick中完成，仍在最近4096缓存 | 原完成结果；拒绝的命令也保持原错误及affectedCount |
| 已分配、已完成，但离开缓存 | ResultExpired |
| 序号0、未分配或其他World令牌 | InvalidToken |
| 旧generation | StaleGeneration |
| Faulted Tick的已取出及剩余Pending | Faulted；此前成功缓存不改写 |

## 未测与限制

- M08编辑预览/正式试玩完整闭环、编辑网格叠加及窗口/DPI全组合尚未实施/验收；M07B-10只证明正式世界读取129×65/0.2及视图切换不改状态。
- Windows Player/IL2CPP和M09真实游戏接入未验；编辑器正式Host通过不等于Player交付。
- P2/P3/P4、稳态GC=0、系统/原生/GPU内存峰值及1920×1080完整渲染帧耗时未验。当前仍有有界候选复制、字典、快照及结果分配；不宣称零GC或全部默认最大容量可在256MiB内运行。显示公开上传字节量和FlushFrame CPU耗时，不能冒充GPU渲染帧耗时。
- 合法height=1中自由固体在紧贴上下边界求解时可能Faulted；已保留原始失败证据。这是M06后续适配边界，不能将所有合法极窄世界的动态固体支持标作通过。
- JSON格式、Schema、四材料默认参数与示例布局未修改，本轮不重复声明Schema或Player验收。
