## 唯一公共签名

实际文件为 `Assets/Scripts/OpenOitaWorld/Core/Contracts/TransactionContracts.cs`：

```csharp
enum StructureDisposition : byte
{
    RetainFixedGrid = 0,
    ExtractFreeGrid = 1,
    RetainBody = 2,
    CreateChildBody = 3
}

StructureComponent(CellPositionKey originalMinimum, string connectionGroup,
    bool isFixed, StructureDisposition disposition, IEnumerable<CellKey> members);
StructurePlan(IEnumerable<StructureComponent> components,
    IEnumerable<ulong> retiredBodyIds = null);

// IPreparedMutation
IWorkingWorldView CandidateWorld { get; }
```

分类、成员及撤销目录均为只读属性。成员复制输入，保留原归属/原局部坐标，不重定原点；原最小键与首成员一致，成员按原y/x严格递增。计划复制分量目录，按Grid、原BodyId、最小y/x严格递增；撤销目录复制、去重、升序且排除0。空体只有撤销记录；旧体单分量保留ID，多分量全部创建子体并撤销旧ID。非法分类、零成员、混代次、排序或分类/撤销矛盾在DTO构造时抛ArgumentException或其子类，不能返回部分可用对象。DTO不搜索连接、不分配BodyId、不判断预算，也不另存材料事实。

CandidateWorld复用既有IWorkingWorldView，由准备对象持有。材料候选只在Prepared租约中提供编辑后状态、全部占据、有效固定标记与原体目录；非材料参与者返回null。Apply/Abort/Dispose、修订/Tick结束、故障后视图失效，Read返回失败/default，无结果码的枚举属性可抛InvalidOperationException。调用方必须先在候选上分析，再对M05/M06全部准备预检，最后Apply；公开查询与显示不能使用候选。完整合同见 [CONTRACTS 1.2](../specs/CONTRACTS.md)。
