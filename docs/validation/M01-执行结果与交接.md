## 容量边界

加载器默认256MiB，可通过 `WorldSourceLoader(long memoryBudgetBytes)` 和 `ConfigurationFileStore(long memoryBudgetBytes)` 为宿主降低加载预算，不向JSON添加未约定字段。DOM前检查输入工作集；运行表发布前检查初态格数、实际触及区块和准备容量。估算公式为：

`文本字符数×64 + 131072 + 材料数×256 + 初态触及区块数×128×128×64 + maxMaterialCells×160 + maxChangesPerTick×96 + maxDynamicBodies×256 + maxTotalShapes×128`。

这是加载阶段的保守预检口径，不是内存实测或整个世界256MiB验收证据。单体/全局形状上限独立，以全局上限约束实际准备量；不以 `maxShapesPerBody > maxTotalShapes` 或 `maxMaterialCells > width×height` 直接认定非法。M02须在每次真实区块分配、结构/几何/物理准备中结合实际对象、字节与保留缓冲再次预检；稀疏4096世界后续若把材料散布到大量区块，应在分配前拒绝，不能由初态加载通过推断未来容量可用。
