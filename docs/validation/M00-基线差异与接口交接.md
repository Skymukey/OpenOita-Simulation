# M00 基线差异与接口交接

日期：2026年10月5日（北京时间）。本记录提交给M01、M02及各模块负责人，在仓库内提供具体差异；没有向未指定的外部聊天或人员发送消息。

## 包依赖处理结论

主方案0.9指定`com.unity.nuget.newtonsoft-json`直接锁3.2.1。当前manifest没有直接声明，packages-lock及实际PackageCache为3.2.2（depth=1）。unity-mcp包声明的下限为3.0.2；静态依赖未发现必须使用3.2.2的约束，但这不是3.2.1实际解析成功的证明。

本轮决定：保持主方案3.2.1目标，M01按C11先添加直接3.2.1并让Unity解析；不手工编辑lock、不回退用户已有包修改。若真实解析要求3.2.2，M01交回解析日志和最小差异，由M00更新主方案版本后再锁实际版本并回归严格加载。本轮没有证据支持提前把设计改为3.2.2，也没有安装/验证3.2.1。

M00夹具使用当前实际3.2.2完成工具解析和测试。Test Framework实际为1.6.0，NUnit包2.0.5；测试asmdef显式引用预编译`Newtonsoft.Json.dll`与`nunit.framework.dll`，不猜测一个不存在的Newtonsoft asmdef。上述包版本决策已记录，实际落锁仍归M01。

## 其他模块接入

M01提供IWorldSourceLoader、IMaterialRuntimeTable、IRuleRegistry，不让Data依赖M03执行器。M03提供RuleId对应的唯一IRuleExecutor绑定及IRuleBatch，裁决归M02。M04提供IStructurePlanner及全部稳定分量；M05提供IMaterialMutationPreparer和IPreparedMaterialMutation；M06提供IPhysicsMutationPreparer、IPhysicsStepper及共享精确几何/接触服务。M07A使用同一令牌/结果/精确几何合同；M07B实现IWorldRenderer并只消费提交视图；M08独占SceneMaterialData并实现泛型转换边界。

新增服务均为合同定义。各模块不得把接口样例或测试拒绝桩接入正式启动，也不得重新定义同名DTO或另写平行几何判断。尚无其他模块负责人实际核对记录，跨模块实现接线仍需后续模块完成。

## 已冻结的补充说明

准备状态增加Applied以区分应用与发布；CellSnapshot仅只读查询/跨阶段边界DTO；不透明令牌以每World唯一对象引用识别所属实例。配置构造器不取代严格加载校验；SceneInitialData负责复制/排序，不擅自丢重复格或修复无效引用。

子步公式采用double累计，角速度上限先转换为内部float弧度单位再比较，避免恰好180度/秒因度弧度往返误差被错误拒绝；不增加速度容差、不裁剪速度。四个边界形状另计，静态形状不受单动态体预算限制。

文件Schema的米与代码Unity世界单位按cellSize统一换算，默认1世界单位=1游戏米；没有修改数值、玩法、Schema或基线样例。主方案、CONTRACTS与模块spec保留原文，由本索引提供实际签名映射。
