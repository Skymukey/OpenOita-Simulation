执行机器（Unity SystemInfo）：Intel Core i7-14700HX、16091MiB内存、RTX 4060 Laptop GPU、Windows 11 10.0.26200。Player实际日志为D3D11、驱动32.0.15.8097。构建产物位于忽略目录Builds/M08Validation；文件测试位于Logs/M08。

## 实现及归属

M08新增 `Data/SceneMaterialData` 和 `SceneEditingDocument`：坐标唯一、非空材料、两个标记、整组预检、覆盖/擦除清标记、复制快照及确定导出。加载失败不更换模型；保存对目标材料/世界引用定义规范化比较，只发布scene.json。严格加载、序列化、刷盘和原子替换继续由M01完成。

Editor新增中文 `SceneMaterialEditorWindow`、`SceneEditorSession`、`InitialSceneRenderView` 和 `PixelPreviewCoordinates`。标准初态预览使用M07B生产渲染器与PixelWorldViewport；只读初态副本不提取、不运行规则。Scene画笔和标准窗口均作用同一编辑模型，矩形预览/执行共用M00 GridSelection。固定/初燃调试层、网格默认关闭，1:1/整数倍与DPI不进入保存数据。

正式试玩使用独立初态文本 → WorldHost → WorldSimulation → 完整M02–M07；自动推进仍为FixedStepDriver，手动Step/Reset/CloseWorld均通过Host，没有第二套模拟器或Physics2D.Simulate。试玩只读点查询使用M07A；Reset按创建初态增加generation并恢复Tick0/满燃料，保存始终来自编辑模型。

共享修改按模块职责落地：M00建立OpenOita.Editor仅Editor程序集和测试引用、GridSelection工具及供Editor复用现有CellState初始化的友元访问；M01增加ReadSourcesWithScene和临时路径诊断；M02增加Host精确像素视图配置及可选Player验证日志；M07B增加显示层隔离，默认层仍0。未修改Simulation/Rules/Structure/Physics推进、默认配置、Schema及原例子。

测试均在可渲染Editor执行，非batchmode/nographics。长液体回归期间MCP主线程请求超时/重连，最终任务仍完整结束；不把连接错误当成功测试。一次测试初始化超时和一次PlayMode转换中的启动拒绝没有测试结果，不计入通过数。

测试临时配置保留于Logs/M08的每例唯一目录。故障清理每次只针对本次唯一临时文件，没有目录扫描清理。最终编译后Console错误数为0；运行参数和原始输出在各测试源码/JSON中。

## 未测与边界

- GPU读回及屏幕坐标DPI函数验证已通过；尚未穷举真实多显示器/OS缩放、Scene不同视角和所有窗口尺寸的人机操作组合。网格和标记是GUI/Handles叠加，不作为材料纹理状态。
- 20轮资源统计证明拥有的Unity对象及独立物理场景不持续增长，不代表原生/CPU/GPU内存峰值或字节级工作集恢复；订阅解除另由窗口OnDisable/重载/选择变化的源码路径检查。
- 保存刷新/关闭失败通过统一M01写入回调在相应阶段抛异常注入，不是物理断电、文件系统损坏或目标目录外部并发修改实测；三文件不构成跨文件事务。
- 第31层用于工具专用摄像机，需留给预览/试玩；当前设计使用单个编辑窗口。打开场景自身仍按Unity进入PlayMode行为运行，工具不改用户场景。
- IL2CPP、M09完整Player操作/10000 Tick、真实游戏接入、P1–P4、GC=0与峰值未验；M06已知height=1自由固体边界限制不由M08规避。

复现：Unity Test Runner运行OpenOita.Tests.EditMode和OpenOita.Tests.PlayMode；M08位于EditMode/M08、PlayMode/M08。菜单和完整操作见[中文操作说明](../M08-编辑初态操作说明.md)。测试暂将EnterPlayModeOptions设为DisableDomainReload以保持MCP任务记录，结束后恢复原值None。

构建自动序列化了URP预过滤/运行设置、Volume filter、Player预载/批处理和Unity服务开关；这些六个文件在开工时均无改动，已仅恢复本次构建/测试产生的变化，差异保留于Logs/M08/build-generated-settings.diff。开工时已有修改的11个文件没有回退。EditorSettings内存和磁盘均恢复None，用户原M05Preview场景保持未修改；中文窗口持有保存副本供操作，不把该场景当正式试玩证据。
