# 验证结果记录

每次运行复制本模板填写；通过、失败、未测三者明确区分。桩测试、Editor实测和Player实测分别记录。

| 字段 | 实际记录 |
| --- | --- |
| 验收ID | 例如M00-01、T7或P3 |
| 实现/合同版本 | 提交SHA、工作区来源及文件哈希；M00-1 |
| 配置版本/哈希 | 材料、世界、场景三个SHA256；专用副本差异 |
| 时间 | 北京时间 |
| Unity/后端/API兼容级别 | 版本、Mono/IL2CPP、实际设置 |
| 实际机器 | CPU、GPU、RAM、OS、驱动信息；拿不到的字段注明原因 |
| 构建 | Editor或Windows Player；Development与否；分辨率、垂直同步 |
| 初态与命令 | 坐标、材料、固定/初燃、体位姿/速度、generation、Tick及同Tick入队顺序 |
| 运行方式 | Test Runner/工具命令/实际游戏调用点；程序集、测试名称或job_id |
| 观察时点 | 初始化Tick0、命令后、结构应用后物理前、每子步、发布后、帧末 |
| 预期 | 使用冻结规格阈值，不测完再改 |
| 实际 | 数值、错误码、affectedCount、版本、资源/时间样本等 |
| 结果 | 通过/失败/未测；说明是合同值测试还是实际模块行为 |
| 日志/原始证据 | XML/JSON、Player日志、Profiler数据、截图路径 |
| 未测原因 | 环境限制、实现缺失、外部接入未落实等具体原因 |
| 集成需求/剩余风险 | 负责模块、接口字段/签名差异及需复验链路 |

性能另附全部样本和活动子窗口、p95/p99/峰值、稳态GC Alloc、模拟CPU资源峰值、初始化/结构分配峰值及回收后余量。预热1000 Tick、采样至少10000 Tick；Reset独立计时排除，初始化后首次Step仍计入。P4独立重建200次，不将64条命令伪装成一条事务。
