## 准备、应用与发布

准备对象状态为Prepared → Applied → Committed；失败路径为Aborted。Applied是补充状态，用于明确“进入工作世界”与“对外发布”不同。它不改变C05事务边界，也不承诺物理求解器回滚。

完整集成要求M02持有全部准备结果，先全部预检，再应用材料/几何/物理资源；旧碰撞在下一求解前撤销，所有阶段成功后才发布版本并MarkCommitted。当前已验证材料状态核心，真实物理和显示参与者仍待接入。Abort和Dispose必须幂等；未移交资源由原模块释放，已移交资源不能由准备句柄再次释放。Applied期间异常不能保证一致时进入Faulted，并冻结公开版本。

FailurePoint覆盖结构/材料/物理准备后、应用前、应用中、物理子步后、发布前。正式模块在这些边界调用注入器；测试实现位于Fixtures，正式装配不引用它。

## 场景编辑转换边界

`SceneMaterialData`由M08在其所属文件唯一定义；M00没有创建第二套编辑模型。M08实现`ISceneInitialDataConverter<SceneMaterialData>`：Export复制三个初态列表并复用M01校验，失败输出null；Import生成独立可写编辑对象。运行体ID、位姿、速度、燃料余量不得保存回编辑场景。创建时保留SceneInitialData副本，Reset用该副本重建。
