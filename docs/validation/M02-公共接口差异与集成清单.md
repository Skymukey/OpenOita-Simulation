## 待实现的正式阶段调用顺序

以下是接线要求，尚不是可运行的Step调用图：

```text
Create：M01全链加载 → M02初态状态副本 → M04全部结构
      → M05全部体/几何 → M06独立物理与边界 → M07B显示准备
      → 全部预检/应用 → 一次发布generation/Tick0/Ready

Step：令牌顺序命令 → 流动前接触 → 水 → 蒸汽 → 合并湿集合/灭火
    → 燃烧 → M04/M05/M06统一结构事务 → 校验并推进每个物理子步/排开
    → 发布快照/结果/ChangeSet → 隔离通知异常 → 帧末显示刷新
```

当前材料状态核心顺序为 `CreateInitial → PrepareInitial（Tick0）/BeginTick+Prepare → PlanStructure → PrepareMaterial → 全参与者Preflight → 同一候选Apply → PublishState → MarkCommitted → Dispose`。状态入口均为internal；M05通过冻结公共合同接入，正式WorldSimulation尚未装配全部服务。准备失败逆序Abort/Dispose；命令预检失败可拒绝，规则/物理失败或进入Apply后的失败要求Faulted。物理子步、完整ChangeSet/守恒台账、令牌与通知尚未实现。
