# 像素粒度整改与验证

日期：2026年10月5日。环境：Unity 6000.3.11f1、Windows Editor、非批处理；项目为OpenOita。

## 结论与范围

本轮已完成M00–M05逐像素回归及独立模块预览整改。现有状态、规则、连通和材料体几何服务保留；未发现必须把这些服务改为另一套粒度的证据。128×128 Chunk是存储分块，碰撞矩形是几何合并，二者都保留逐像素状态。

旧预览逐格留缝且随GUI布局缩放，缺少1:1与倍率说明，容易把显示方块当成复合模拟单元。本轮改为逐像素Point纹理、默认1:1、显式整数倍及独立调试叠加。独立探针仍自有256×256、cellSize=0.1配置，并在界面明示；8×8模板展开仍创建64份独立状态，不是降低模拟分辨率。

依据用户要求，配置回归、逐像素夹具/核心回归、预览整改三个子任务均使用gpt-6.1-sol、high。主任务完成合并检查、Unity编译、统一测试、实际输出验证及文档更新。
