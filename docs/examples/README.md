# 配置示例、像素粒度与规则夹具

2026年10月6日设计修订：[M06-F01](../specs/M06-F01-水汽暂存与恢复.md)/公共合同1.10已有本轮正式World和Editor功能证据，详见[实现记录](../validation/M06-F01-实现与验证.md)。现有三文件样例及schemaVersion=1不变；maxMaterialCells=65536运行总量须包含暂存，fluidDisplacementRadius=16用于恢复路径上限。scene.json仍只保存175格编辑初态，不增加暂存字段；Create/Reset的Tick0暂存为0。运行中隐藏数量须从同版本诊断核对，不能仅凭画面或普通查询总数判断丢料。

日期：2026年10月5日｜对应[公共合同C01（1.5）](../specs/CONTRACTS.md#c01-数据与坐标)及[实现方案5.3](<../OpenOita 初步实现方案 草案.md#53-像素粒度与显示约定>)。本文解释现有三文件，未改变JSON数值或格式版本；独立模块预览已通过本轮Editor验证，正式显示/编辑集成仍待验收，见[整改记录](../validation/像素粒度-整改与验证.md)。

**一个逻辑像素 = 一个模拟格 = 一份独立材料状态 = 一个原始材料纹素。** 屏幕显示倍率单独控制，不写入世界或场景JSON。

| 文件／参数 | 示例含义 |
| --- | --- |
| [world_config.json](world_config.json)的width=256、height=256 | 65536个可寻址逻辑像素位置，非空像素按实际布局计数；不表示256个大格中还含有另一层待模拟像素。 |
| chunkSize=128 | 每个存储块容纳128×128个独立状态，不作为一个整体执行水或燃烧规则。 |
| cellSize=0.1 | 每逻辑像素边长0.1世界单位，主网格世界宽高均为25.6；改变该值不会增加逻辑像素数量。 |
| [scene.json](scene.json)的cells | 175项对应175个非空逻辑像素，其余合法位置为空；每项只初始化一个坐标，不作8×8展开。另有2个固定标记、1个初燃标记。 |
| [materials.json](materials.json) | 共享材料定义；各像素只按材料ID引用共享属性，运行中的燃料、寿命等状态逐像素保存。 |

对齐主网格且关闭调试叠加时，1:1显示占256×256画面像素；显式3倍显示占768×768画面像素，但可寻址逻辑位置仍为65536，非空材料仍为175。单像素擦除在两种倍率下都只修改一个逻辑坐标；窗口缩放不改变数据或模拟结果。标准预览默认1:1，网格线默认关闭，窗口不足时裁剪或平移。

若要在相同25.6世界单位范围内使用768×768个独立逻辑像素，需要将宽高增至768、cellSize相应设为25.6/768，并明确生成新布局及重新检查容量、内存与性能。其可寻址位置为589824；满图材料和一次全图写入均超过示例65536预算。该例只解释参数关系，不是已验证可用的性能配置，也不应直接覆盖现有示例。

模块探针若将模板中的一个标记展开为8×8，应显式生成64个坐标及独立状态，并显示展开后的逻辑分辨率。该操作属于初态生成；显示放大只改变画面覆盖，不增加状态。

液体规则新增[液体平衡验收夹具](液体平衡验收夹具.md)，对应[M03-L01](../specs/M03-L01-液体扩散与液面平衡.md)。其中F1–F4规定水槽、平台、长通道、隔墙与开通的逐格生成配方，供测试生成现有格式的场景数据；不是加载器新增的矩形字段，不覆盖当前scene.json。材料仍用liquid_flow/moveIntervalTicks=2，Schema只同步字段说明，未增加配置键。L01纯规则、M02原子链提交核心及独立预览已通过Editor验证，见[液体实现记录](../validation/M03-L01-液体平衡实现与验证.md)；正式World/Player、真实跨归属物理和性能仍待验收。
