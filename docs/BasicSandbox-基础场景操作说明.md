# 基础地图沙盒

2026年10月8日最新设置：默认CPU内存预算预检拒绝已关闭，当前不以256/512MiB估算上限阻止世界启动和推进；材料、形状、变化数等数量限制保留。下文512MiB说明为之前的临时设置。

场景：`Assets/Scenes/BasicSandbox.unity`。关卡：`Assets/OpenOita/Maps/BasicSandbox.asset`。

画布为 **960×640 格**。cellSize保持0.1，世界范围为96×64单位。此次缩小画布时，裁掉了边界外的3448格材料；保留33803格材料、320个固定标记及1个初燃标记。空白区域按需分配。

## 编辑与观察

1. 打开场景，选中Hierarchy中的“基础沙盒地图”，点击Inspector的“编辑地图”。已绑定独立关卡资产，无需导入JSON。
2. 使用Scene窗口绘制整幅地图：鼠标滚轮缩放，鼠标中键拖动平移；绘制窗口选择材料、画笔大小、圆形/方形或矩形。也可使用窗口的整数倍率与格平移查看局部区域。B为绘制，E为擦除，R为矩形。
3. 固定平台使用“固定”标记；木头使用“初燃”标记可观察燃烧。替换或擦除材料会清除该格旧标记。绘制在停止Play时进行。
4. 点击“保存初态”或地图Inspector的“保存关卡”，保存关卡.asset。修改对象、摄像机或引用后，再按Ctrl+S保存Unity场景。
5. 点击Unity Play或“正式试玩（使用本对象Host）”。地图自动推进；绘制窗口可观察Tick、材料数量、暂存数量及点击查询。Game窗口的“Reset地图”恢复保存的初态；停止Play后继续编辑。

Scene视图可定位整张地图。Main Camera默认对准左下角演示区域，避免整幅画布把示例缩得难以观察；观察新区域时，选中Main Camera调整Position X/Y和Orthographic Size。全图视角可设置Position=(48,32,-10)，Orthographic Size=34（宽高比至少1.5时可容纳全图）。Game采用自由视角，窗口整数倍率用于精确像素查看。

## 初始演示内容

坐标范围均含端点；X向右、Y向上。所有混凝土格均固定。

| 内容 | 坐标 | 行为 |
| --- | --- | --- |
| 地面及挡水边缘 | 地面x=3–92,y=2–3；两侧x=3–4及91–92,y=4–8 | 承接水流 |
| 左侧平台与水 | 平台x=10–35,y=18；水x=13–20,y=23–30 | 水落到平台后摊开、溢流 |
| 蒸汽 | x=42–45,y=8–10 | 漂移并按200 Tick寿命消散 |
| 悬空木块与承接平台 | 木块x=47–52,y=42–44；平台x=43–58,y=34 | 自动提取为刚体，下落、碰撞 |
| 燃烧木梁 | 木梁x=66–82,y=32–33；初燃(68,32) | 火焰扩散、烧损、燃尽 |
| 木梁支柱及承接平台 | 支柱x=66–67,y=4–31；平台x=63–86,y=24 | 承接燃烧拆分后的材料 |

基础示例布局合计448格：混凝土320、水64、蒸汽12、木头52；固定320格、初燃1格。保留现有规则及资源配置，默认禁止刚体旋转。承接平台将自由落体距离控制在现有5 m/s速度上限内；移动示例时可相应移动承接平台。

画布面积与非空材料容量独立。本场景保留现有maxMaterialCells=65536；2026年10月8日当前统一运行预检预算临时提升为512MiB，M09原内存验收目标仍为256MiB，预算调整不表示内存问题已解决。大画布不表示可同时填满61440000格。空白区域不预先填充材料。
