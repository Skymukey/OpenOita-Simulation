# M08 编辑初态与正式试玩

适用版本：Unity 6000.3.11f1，公共合同1.10。菜单为 **OpenOita → 场景绘制工具**，原菜单“编辑初态与正式试玩”仍可用。工具保存的是编辑初态，不保存水汽暂存记录、中途燃料、寿命、体位姿、速度或Tick。

## 从空白场景开始

1. 展开“新建空白场景”，填写场景名称、宽高（逻辑格）和每格世界尺寸，点击“创建空白场景并开始绘制”。无需手工编写JSON或先复制配置。
2. 初次创建复用项目 `StreamingAssets/OpenOita` 的已校验材料与世界规则；已有文档时复用当前材料和规则。只按填写值改变新画布尺寸与cellSize，材料容量、物理及内存预算不自动提高。已有绘制切换为空白场景前会提示保存。
3. 选择材料，选择“绘制 + 连续画笔”，调整1–128格的画笔大小，选择圆形或方形，按住左键绘制。大小1只改一个逻辑格；快速拖动会连接相邻鼠标事件，避免漏点。
4. 选择“橡皮擦”即可用相同大小和形状擦除。选择“矩形工具”后，从一角拖到另一角，松开填充；与橡皮擦组合则矩形擦除。拖动时显示宽高，按Esc或在画布外松手取消未提交矩形。
5. 鼠标位于画布时，B切换绘制画笔、E切换橡皮擦、R切换矩形；`[`缩小、`]`放大画笔。矩形保留当前绘制/擦除操作。输入文本时不响应这些快捷键。
6. 点击“保存初态”，选择父目录，工具在其中创建以场景名称命名的新目录，保存完整三文件。随后可正式试玩、退出后继续绘制。这里创建的是材料场景初态，不新建或替换Unity `.unity` 场景。

画笔超出画布的部分会在选格阶段裁掉；底层模型仍严格拒绝非法坐标。圆形以格中心是否落在直径内判定，偶数大小的范围向右/上多一格，以光标预览为准。鼠标离开画布后重新进入不会跨越外部区域连线。连续笔触已经画下的部分立即生效，Esc只结束当前笔触；本轮未增加撤销/重做。

## 加载与编辑

1. 点击“选择目录并加载”，选择含 `materials.json`、`world_config.json`、`scene.json` 的目录，也可明确选择该目录的 `scene.json`。首次体验可选择仓库 `docs/examples`；建议先将三文件复制到自己的工作目录。
2. 三文件经过M01严格加载，成功才替换窗口模型；失败显示错误码、文件、字段、阶段和原因，保留当前编辑数据。材料菜单来自校验后的材料表，支持稀疏ID。
3. “绘制”或“橡皮擦”与“连续画笔”或“矩形工具”组合使用。单格操作把画笔大小设为1。“固定”和“初燃”也使用当前选格，分别要求structure与burnable材料；关闭“设置标记”可取消。含不合法标记目标的笔触整组拒绝。
4. 绘制覆盖已有格，即使ID相同，也清除旧固定/初燃标记；擦除同样清除。需要标记新材料时显式重设。
5. 标准像素预览默认1:1，可点击3倍或输入1–16整数倍；整数格平移用于查看窗口外区域。界面按DPI将实际输出像素映射到GUI点，不拉伸适应整幅世界。倍率和平移只改变显示，不改变材料数量、尺寸或cellSize。
6. 网格及青色固定/黄色初燃标记是独立调试叠加层，默认关闭。白色区域为实际画笔选格，擦除显示红色；灰色边框标出画布范围。Scene自由视角不代表1:1；点击“定位Scene画布”会开启Scene画笔、切到2D并定位完整画布，也可只勾选“启用Scene画笔”保持当前视角。

世界原点可显式设置，X右、Y上，右上逻辑边界不包含。窗口显示加载的真实逻辑尺寸与cellSize，不硬编码为演示配置。选中Host若有旋转或非单位世界缩放，编辑/试玩明确拒绝；工具不会自动修正其变换。

## 保存与失败恢复

已加载或已保存的场景，“保存初态”只原子更新当前目录的 `scene.json`，不会改写两个引用文件。三个数组按y/x排序，坐标唯一，空格不输出。

“另存新场景”把当前材料、世界配置和绘制初态一起保存到新的场景目录。名称在“新建空白场景”展开栏修改，再选择父目录；目标目录已存在时拒绝，不覆盖已有场景。新目录逐文件原子写入，最后发布 `scene.json`，不是跨三文件事务；中途失败保留诊断及已写入文件，请选择新的目录重试，工具不会批量清理。已有目录的材料或参数不匹配时，普通保存仍拒绝。

加载后若磁盘引用配置被修改，保存预检会发现不匹配。确定需要使用新的配置时，先保存/保留现有工作，再明确重新加载。工具不猜测ID映射，不自动迁移，不扫描材料目录。

保存使用M01同目录唯一临时路径、完整写入、刷盘/关闭、最后原子替换/首次移动。写入或发布失败保留旧目标，首次失败不会出现部分目标。诊断包含本次临时路径；M01只尝试删除该单一明确文件。若清理失败，按诊断自行检查该临时文件；工具不扫描或批量清理目录。测试文件保留在 `Logs/M08`，需要批量清理时由用户手动处理。

## 正式试玩

临时观察开关“禁止刚体旋转”默认勾选。木梁及碎片仍会下落、平移、碰撞、燃烧与拆分，但不会翻倒或翻滚。进入试玩后开关不可改，Reset保留进入试玩时的设置；要恢复旋转，请退出试玩、取消勾选，再开始试玩。保存初态不会把这个观察开关写入JSON。

直接运行`SampleScene`时，WorldHost的Inspector也有“禁止刚体旋转（重新启动生效）”，默认开启。停止Play Mode后修改，再次运行生效；在运行中修改该字段不会改变现有世界，Reset也不会读取新字段。自定义接入可使用`new WorldSimulation(freezeBodyRotation: true)`，直接调用工厂而未传此参数时仍允许旋转。

该开关只冻结角度，不对齐连续平移坐标，因此不能完全消除逻辑像素边缘的部分覆盖。被固体覆盖的水汽现已进入暂存集合并暂时隐藏；从下一Tick起优先原格、再附近恢复，没有空位就继续等待，不因无目标停步。暂存材料仍计总量，蒸汽寿命继续每Tick扣减；真正资源、速度或边界故障仍按合同处理，见[F01规则](specs/M06-F01-水汽暂存与恢复.md)及[实际验证](validation/M06-F01-实现与验证.md)。

“正式试玩”会进入Unity PlayMode，对编辑初态序列化并独立复制，再通过 `WorldHost.CreateWorld → WorldSimulation.Create` 创建完整M02–M07世界。未固定结构自动由M04/M05提取，M06独立物理场景真实运动；初态预览不进行这些操作。

自动推进使用现有Host/FixedStepDriver；关闭“自动推进”后可点击“推进1 Tick”。两种驱动互斥。试玩期间工具和原点输入暂停，窗口显示生命周期、generation、Tick、活动网格/体内格数、暂存水/蒸汽数及材料总量；点击画面可用正式QueryPoint读取同版本活动材料/归属，隐藏水汽不产生命中。运行变化不会回写编辑模型，“保存初态”始终保存进入试玩前的编辑布局。

“Reset”调用Host的正式Reset，重建创建初态、清全部旧暂存、增加generation、回到Tick0，初燃恢复满燃料。“退出试玩”关闭世界、暂存集合、显示与物理资源，恢复初态预览；它不自动退出Unity PlayMode。退出Unity PlayMode也会关闭窗口拥有的试玩。选择Host变化、关闭窗口和脚本重载均释放窗口拥有的预览/试玩及订阅，不关闭用户自己的Host。

进入PlayMode时当前打开场景仍遵循Unity原有行为；窗口的专用摄像机只显示第31层的预览/试玩资源。第31层应留给该工具使用，同一时间使用一个编辑窗口。不要在该层放置游戏内容。用户场景、全局时间和全局物理设置不由工具改写。

关闭窗口前请保存需要保留的修改；编辑模型是窗口持有的初态，不能把临时窗口数据当作已保存文件。运行程序集不含UnityEditor；Editor UI通过独立 `OpenOita.Editor` 程序集隔离。Windows构建/实测边界和按编号结果见 [M08验证记录](validation/M08-编辑器与保存实现验证.md)。
