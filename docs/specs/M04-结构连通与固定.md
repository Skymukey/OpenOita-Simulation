## 1. 目标与非目标

根据只读候选世界，找出全部结构连通分量，判定哪些主网格分量仍有有效固定点，以及哪些主网格分量须提取、哪些动态体须拆分或撤销。结果是完整、稳定排序、可预检的结构计划。

M04 不直接增删格、转移所有权、分配 BodyId、创建刚体、修改碰撞器或发布事件；这些由 M02/M05 的事务链提交。M04 不做矩形合并、质量惯量、速度继承、物理接触、焊接、应力、弯曲和过载断裂，也不把一格碎片丢弃。

## 4. 输入输出合同

### 4.1 输入

分析输入是初始化布局或一次待提交事务之后的**候选视图**，不是尚未修改的旧世界。调用方提供：

- 主网格和待分析动态体的全部实际非空结构格、局部坐标、原归属及可追踪材料身份。
- 共享材料表中的 `structure` 能力和 `connectionGroup`，不以名字、颜色或材料 ID 判断连接。
- 旧固定标记及本事务中发生 Remove/Replace 的原材料实例集合；由此得到候选视图上的有效固定点。
- 受影响归属集合、输出与工作缓冲，以及由调用方提供的容量限制。

输出必须覆盖所有受影响归属的完整分量，不得只从被编辑格附近选一个块。是否重算整个主网格可由实现决定，但局部算法必须证明不会遗漏远端因桥接格删除而断开的分量。

### 4.2 连通和固定规则

同一主网格或同一 `BodyId` 内，只有四邻接且 `connectionGroup` 完全相同的结构格连接；连接组使用大小写敏感序数比较，与标签/名称规则一致，`building` 与 `Building` 属于不同连接组。木头和混凝土默认都属 `building`，可以连接。

不跨归属建立结构边。两个动态体接触、动态体碰到固定地形、动态体与新 Spawn 固体接触，都不能合并或自动焊接。液体、气体、空格和角点接触不提供结构连接。世界边界碰撞形状不是材料，不能成为固定点或连通节点。

固定标记只属于主网格结构材料实例。主网格分量含至少一个仍有效固定格时，整个分量留在主网格；没有有效固定格时，整个分量进入待提取结果。Remove 或 Replace 撤销原固定标记，包括 Replace 为同一种材料；不能因为位置或 ID 恰好相同而恢复旧固定点。新增固定标记只能来自编辑初态；公开 Spawn 没有固定操作。

动态体内每个非空分量都是自由分量，不因碰到地面重新固定。既存动态体剩一个分量时计划标记“保留原体身份并更新”；剩多个分量时标记“撤销原体并为全部子分量创建新体”；为空时标记“撤销原体”。主网格自由分量始终需要新非零 BodyId，即使整个主网格只有一个自由分量，也不能保留主网格的 BodyId=0。具体 ID 分配由 M05 执行。

### 4.3 输出计划

对外只返回 M00 冻结的公共 `StructurePlan`。每个分量至少携带原归属、稳定排序键、完整成员格身份/坐标、成员数量、有效固定点信息及结果分类。计划须能使 M05 取得原 `CellState`，不重新初始化燃料、寿命或燃烧标记。

结果分类至少包括：保留主网格固定分量、待提取主网格自由分量、保留原动态体的单分量、待新建动态子分量、待撤销空体。分量最小大小为一格；空体只有撤销记录，不生成空分量。

按原归属稳定键（主网格优先，其次旧 BodyId）、分量最小 `y/x` 排序，分量内按 `y/x`。排序使用重定局部原点之前的原归属坐标系，不能因子体重新选局部原点而改变新 ID 顺序。M05 在准备阶段可预留新非零 BodyId，用于新归属位置计数、映射和物理准备；事务提交后才发布。失败预留的 ID 在同 generation 内也不复用；M04 不分配或预留 ID。

M00 在开始联合实现前冻结计划成员存储形式、借用视图有效期、失败返回及缓冲拥有者，并将上述排序和预留规则写入公共类型与断言。固定点与湿接触的材料身份迁移必须共用合同。

输出是只读准备结果。若工作缓冲不足或发现无效引用，整次分析失败，不能返回部分分量冒充成功。最终 `maxDynamicBodies`、形状、材料及变更预算由 M02/M05 联合预检；M04 可提供数量统计，但不能擅自忽略某个分量满足预算。

## 5. 实现检查项

- 初始化就检查所有结构格；无固定点的初态结构自动进入提取计划。
- 结构格 Spawn、Remove、Replace、燃尽均触发分析；替换为不同连接组即使格数不变，也要重新分析。
- 主网格邻接跨越区块 127/128 边界；尾块超出逻辑世界部分不可作为节点或邻格。
- 缺块读取返回空，不为遍历创建区块；结构查询不改变世界材料数和分配状态。
- 每个结构格恰属于一个输出分量，不重复、不遗漏；集合并集等于对应候选视图中的全部结构格。
- 固定分量与自由分量的成员不交叉；有效固定点不得出现在动态分量。
- DFS/BFS 使用显式复用缓冲；不对可能数万格的分量使用依赖调用栈深度的递归。
- 不以结构分量数量替代实际动态体/碰撞预算；保留既存未受影响体的数量由提交方一并计算。
- 同样输入、不同插入/字典遍历顺序必须得到同样的有序计划。
- 不在本模块写世界、分配 BodyId、更新 NativeArray 所有权或直接调 Unity 物理 API。

| --- | --- | --- |
| M04-T3-01 混材固定 | 混凝土 `(10,10)` 固定，木头 `(11,10)/(12,10)`，均 `building`；分析初态，再分析移除 `(11,10)` 的候选视图 | 初态一个三格固定分量；移除后一个一格固定分量和一个一格待提取分量；由 M05 集成后 `(12,10)` 成为一格动态体 |

| M04-T4-01 全部分量 | 固定中心 `(4,4)`，四条臂 `(2,4)/(3,4)`、`(5,4)/(6,4)`、`(4,2)/(4,3)`、`(4,5)/(4,6)`；删除中心 | 完整返回四个两格自由分量，总数八格，稳定排序且无遗漏 |
| M04-T4-02 预算联合 | 在上述九格初态，把动态体容量设为 3，再执行删除中心的外部命令 | M04 仍报告完整四分量；M02/M05 整条拒绝，原九格及固定约束保留，没有前三个体的部分成功 |

| M04-T5-02 不焊接 | 输入两个接触中的独立动态体，以及接触固定地形的动态体；在附近 Spawn 主网格固体 | 不产生跨归属结构边；各原体保持独立分析，Spawn 仅参加主网格连接 |
| M04-T9-01 燃尽桥接 | 固定结构与自由端之间只有一个燃烧桥接格；向分析器提供该格燃尽后的候选视图 | 全部断开部分都成为自由分量；成员仍保留原燃料和 Burning 状态引用，M04 不重置状态 |
| M04-T7-01 只读失败 | 对大分量提供不足工作缓冲；对正常夹具打乱插入顺序后重复分析 | 前者明确失败且输入不变；后者有序计划完全相同；不得生成部分分量或分配物理对象 |
| M04-T3-06 初态自由结构 | 无固定点的单格、带中心孔的环形结构分别创建 | 单格不能被过滤；每个主网格自由分量均标记需新非零 BodyId；环形成员集合保留孔洞，M05 后续几何不能补洞 |
| M04-T4-03 排序与预留联合 | 打乱四臂夹具的输入顺序，并让 M05 重定子体局部原点；准备新 ID 后注入失败，再重试合法事务 | M04 始终按原归属坐标生成相同分量顺序；失败的预留 ID 未公开且不复用，合法事务按相同分量顺序获得后续新 ID |

M04-T4-02 是事务集成用例，不能仅断言“计划数量为 4”就写为整条通过。M04-T5-01 不负责证明世界位姿或速度继承，但必须把所有结果分量交给 M05 验证。
