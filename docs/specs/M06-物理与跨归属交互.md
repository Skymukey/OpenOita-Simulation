## 1. 目标与非目标

在独立 Unity 2D 物理场景中推进 M05 自动提取的材料体，建立准确的世界材料格几何索引，处理跨归属燃烧/灭火接触、运动体覆盖水汽的整批暂存与有界恢复，以及子步、速度、占据和边界故障。

不模拟液体压力、浮力、水汽对刚体反作用、自动焊接、烟灰、耗氧、额外冲量或渲染插值。不以手工预置刚体替代 M05 自动提取。碰撞事件不直接等同于材料接触，AABB 不作为实际材料命中的最终判据。

## 5. 实现检查项

### 5.1 独立场景与质量应用

临时禁转补充（2026年10月6日）：由创建参数`freezeBodyRotation`选择；为所有动态体应用`RigidbodyConstraints2D.FreezeRotation`并保持角速度为0，覆盖首次准备、结构重建应用和内部同步路径。不把位姿角强制归零，不限制平移，不改变全局Physics2D。正式初态来自轴对齐网格，因此从初态重启后保持水平/垂直；开关关闭时继续执行下列原旋转合同和全部历史旋转测试。Reset保留创建参数。见[实现记录](../validation/临时禁止刚体旋转-2026-10-06.md)。

1. 为每个世界创建独立 2D 物理场景，由唯一 Host 通过 M02 手动推进；不推进默认场景、不重复推进，不修改宿主全局重力和固定步长。
2. 每个动态材料体只有一个 `Rigidbody2D`；每个 M05 矩形对应一个 `BoxCollider2D`。静态几何保持真实占据和孔洞。
3. 结构准备完成后，在求解前撤销旧碰撞，再应用新几何。关闭自动质量计算，显式设置质量、局部质心、惯量，随后恢复 M05 计算的线速度及角速度；弧度/秒与 Unity 度/秒只在适配边界转换。
4. 持续保持 `gravityScale=0`。每个子步开始用 Force 模式施加 `M × (0, gravityY)`，随后求解 `h/N` 秒；力不再乘 h 或 N。
5. 世界四边分别建立一个厚度为 cellSize 的静态 BoxCollider2D，放在逻辑范围外，内表面与边界齐平。4 个形状单独计数，不消耗材料格、不进入材料查询，也不挤占 `maxTotalShapes`。
6. Host 保持旋转 0、缩放 1，运行中 origin 不变；不靠改变 Host Transform 移动物理世界。

### 5.2 子步、运动与故障

1. 严格按公共合同 D08，对每体计算 `d = |v|h + |gravityY|h² + |omega|rh`，其中 `h=stepSeconds`、omega 为弧度/秒，r 是质心到最远实际占据格顶点的距离。取全体最大 d，`N=max(1,ceil(d/(cellSize/2)))`；无动态体时 N=1。N 不超过 `maxPhysicsSubsteps`，预测及实际速度都受预算约束；不能用局部几何原点或 AABB 中心代替质心计算 r。
2. N 个子步总时间严格等于 stepSeconds。超子步或速度预算返回明确失败并交 M02 进入 Faulted，不截断速度、时间或位移以伪装成功。
3. 每个子步后检查实际边缘位移、线速度/角速度、完整材料格几何边界以及不同归属固体的交叠；不能只检查刚体质心或包围盒中心。
4. 固体间真实格的最小分离平移深度允许 ≤ `0.1 × cellSize`；完整固体几何超出逻辑世界矩形的最大距离也允许 ≤ 此值。超过即 Faulted。该预算仅用于物理求解误差，不能用于 Spawn 重叠或材料接触。
5. 物理解算可能已经推进；故障不承诺回滚求解器。失败 Tick 不发布 committedTick、位姿、命令成功结果或显示；普通材料查询禁用，配置和诊断仍可读，恢复通过 Reset/Dispose。

### 5.3 精确空间几何与接触

1. 主网格格中心使用 `origin + cellSize × (x+0.5, y+0.5)`。动态格用局部原点与连续位姿变换为真实正方形；局部数据不随世界采样改变。
2. 空间索引仅作候选筛选，最终判定使用真实格正方形。记录 ownerKind、BodyId、局部坐标、材料实例身份和工作版本，避免把空洞当作占据。
3. 同一主网格或同一 Body 内接触为严格四邻接；不因为 epsilon 把同归属对角格连起来。
4. 跨归属计算 OBB 最近特征距离；距离 ≤ `epsilon=1e-4×cellSize` 且为边–边或顶点–边时接触，只有顶点–顶点相切不接触。正面积交叠也算接触，但仍需执行物理合法性和水汽暂存检查。
5. Unity 接触回调、contact offset 和 AABB 相交都不能直接决定传播/灭火。精确距离阈值不得扩大到物理微穿透预算。
6. 提供 M07A 所需精确辅助函数：点是否在真实格面，世界矩形是否包含实际格中心，线段是否与真实格正方形相交及首次沿线距离，Spawn 格与动态固体是否有正面积重叠。
7. 查询稳定顺序由公共合同执行：点多命中主网格优先，再 BodyId、局部 y/x；区域与线段按格身份去重，线段按距离及稳定格键排序。精确函数不得返回包围盒孔洞假命中。

### 5.4 水接触时序

由 M02 在外部命令后、流动前建立湿集合，M03 在流动后补充；本模块提供跨归属精确接触，并在物理前、每子步暂存前后以及最终恢复后继续检查；隐藏锚点不产生接触。

湿集合绑定材料实例，本 Tick 只增加，下一 Tick 重建；相同坐标 Remove/Replace 后的新材料不能继承旧实例的湿标记。物理阶段新接触水的燃烧格立即熄灭，最迟本 Tick 发布时生效；不撤销已在燃烧阶段完成的燃料消耗。熄灭交由 M03 的统一状态操作清 Burning/IgnitedTick、重置传播周期并保留燃料，不在适配器内重复实现规则。

水不被灭火消耗或变为蒸汽。水流走前发生的有效接触必须保留；同 Tick 先 Remove 水再 Ignite 的行为由命令后首次接触检查保证。

### 5.5 水汽整批暂存与恢复（1.10替代条款）

1. 每子步以真实固体正方形的正面积重叠收集活动水汽，源按y/x排序去重；记录有效水接触。几何共边或相切不算覆盖。
2. 原子准备候选位姿、源清空、完整状态暂存与实例映射；总量不变，不要求即时空位。新记录最早下一Tick恢复；隐藏记录没有活动占据、接触、查询或显示。
3. 全部子步成功后，按进入Tick、原y/x、记录ID顺序尝试恢复旧记录。优先原格，然后按四邻接路径距离/y/x搜索，最多fluidDisplacementRadius格；目标为最终固体外的活动空格且未被预留。
4. 动态覆盖的锚点允许作为起点，后续节点不可穿最终固体；静态覆盖锚点直接等待，路径不穿墙角/世界边界。可经过水汽但不改中间格。使用最终位姿，取消旧的起止两套占据阻断规则。
5. 能恢复的记录联合预检后整批采用，其他记录保持等待。无目标不Faulted；真正容量、变更、CPU资源或内部故障仍不发布Tick。不得丢弃记录、覆盖材料或用部分采用掩盖资源失败。
6. 暂存蒸汽每Tick寿命一次更新及自然消散由M03/M02处理；总量、记录键计数、版本与生命周期由M02管理。完整规则和F01-01–10验收见[M06-F01](M06-F01-水汽暂存与恢复.md)。

### 6.1 自由落体探针的固定夹具与误差预算

本节是本次规格拆分补充的技术默认，半隐式 Euler 为参考积分假设。2026年10月6日已按冻结夹具实测通过，详见[M06记录](../validation/M06-实现与验证.md)；配置与断言未按实测放宽。后续若不同平台实测显示积分方式不同，应先调查原因，再记录版本化修订。

- 使用默认256×256世界、cellSize=0.1、h=0.02、gravityY=-9.81。两独立单格体中心分别为 (1,2)、(3,2)，由测试材料配置令每体质量分别为1和10；相同几何，线速度和角速度初值均为0。
- 关闭线性/角阻尼，禁止睡眠，无约束、无接触；gravityScale=0。起点及整个轨迹远离边界、其他固体和水汽。
- 每档从相同初态重建，测试专用固定 N=1/2/4/8，分别推进10 Tick，总时间 T=0.2秒。专用档位不暴露为正式可变步长 API；该短轨迹下N=1的最大边缘位移也低于cellSize/2，且速度低于默认预算。
- 再运行gravityY=0对照，位置和速度应保持初值；默认物理场景另设对照对象，在关闭其他驱动的受控夹具中确认本世界Step不会额外推进它。

连续解析参考：`v(T)=gT=-1.962` 世界单位/秒，`y(T)=y0+0.5gT²=y0-0.1962`。若每子步采用先更新速度再更新位置的半隐式 Euler，令 `dt=h/N`，则离散位置为 `y0+0.5g(T²+Tdt)`，其相对解析轨迹的有符号偏差为 `0.5gTdt`，绝对值为 `0.01962/N`。

每档断言：`|vy-gT|≤1e-4` 世界单位/秒，`|y-y解析|≤0.01962/N+1e-4` 世界单位；两质量终速度差≤1e-4世界单位/秒。零重力对照的位置误差≤1e-4世界单位，速度误差≤1e-4世界单位/秒。
