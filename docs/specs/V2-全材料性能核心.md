# V2 全材料性能核心

日期：2026年10月8日。用户已批准整体重构，无旧算法/接口兼容要求；本规格优先于旧M02–M07的全量快照、原子水链、固定128模拟块和整Tick回滚条款。

状态：新核心已实现并接入正式Host、绘制工具与试玩。Unity定向回归EditMode 63/63、PlayMode 41/41通过；Windows Mono Player的14项完整Tick长测、13项稳态分配长测、3项完整显示长测及3项显示准备分配长测均通过。正式Host已推进到Tick1000并验证实际URP画面。原始数据与验收范围见[整体验收报告](../validation/V2-整体重构与验收-2026-10-08.md)。

## 核心约束

- 目标100万非空格、10万活动格；当前BasicSandbox由另一任务调整为960×640/33803格，保留最新关卡。另建大画布及百万格夹具。
- 32×32模拟页，128×128显示页。画布只有页目录，缺页读取为空且不分配。材料页来自固定大小slab，不因页池增长搬迁。
- 热数据为材料、方向、下次可移动Tick、处理Tick及冷组件句柄；冷组件保存燃料/寿命/传播绝对时间，移动只改位置，句柄保持。
- 直接更新唯一状态；局部命令先预检，内部故障停止并Reset。外部读取在完整Tick屏障，下一Tick使读取租约失效。
- 内部水受阻休眠，水面允许局部活动。水从下往上、蒸汽从上往下按相邻空格更新，最多移动一格。不使用原子链/BFS出口/最低落点搜索。
- 物理仍支持真实旋转、逐格破坏、提取和拆分，不以停用结构或碰撞换取性能。
- 不恢复CPU内存预算拒绝，不增加托管堆采样。

## 并行与事件

区块颜色为(cx&1)|((cy&1)<<1)，Tick确定颜色顺序。每个核心任务写材料到自身及一格边界；唤醒可扩展两格，同色区块相距64格，区域仍不重叠。只有跨核心页的位图字需要原子OR；不得依赖线程完成顺序裁决材料目标。

同份材料写目标处理Tick，避免后续颜色再次移动。核心页内部新空位可唤醒后续位置；已经处理的位置留给下一Tick。普通规则只枚举活动位图，不按非空材料建立全世界输入。

冷组件采用四级256桶时间轮，删除时脱链并复用槽位，槽位代次递增。蒸汽休眠/暂存仍到期。燃烧先收集点燃请求，阶段末应用，新火不当Tick递归传播。燃烧前接水不扣本Tick燃料；物理后接水不追溯返还。火焰显示使用量化燃料，仅实际可见变化上传。

## 执行与集成

命令→移动前接水→水/蒸汽→灭火/燃烧/延迟点燃→增量结构→物理子步/接水/覆盖→暂存恢复→发布。

同一Tick已入队的编辑命令作为一批进行结构/数量预检。预检仅复制受影响连通组件，按命令顺序构造局部草稿；任何预检失败则整批拒绝，不写正式材料。显式编辑可分配草稿，普通无命令Tick不建立草稿。

`Published`通知包含版本、材料总数、规则尝试数、变化块数及体事件数。读取租约可逐项读取变化块和体创建/移除/位姿/拓扑事件；下一Tick使租约失效。记录在写入和规则任务屏障产生，不比较两份世界。发布回调允许读取，禁止重入推进、Reset、释放或入队。

结构只读取结构目录，维护页内组件及边界连接图，删除后检查受影响图分量。位姿与材料几何分离，休眠体在支撑/附近变化时唤醒。静态格直接寻址，体级候选后做局部精确几何，接触/覆盖/验证复用候选缓存。

恢复原位优先、半径4格、下/左/右/上固定邻接、每Tick4096候选访问，未完成记录轮转。无位置等待占据变化；暂存总量纳入守恒。

V2普通配置严格要求三文件schemaVersion=2，world不接受chunkSize。迁移是显式另存，保留原始资产；Editor可读取v1以供迁移，不把兼容逻辑放进V2运行Loader。

## 验收

水/汽32边界及127/128跨显示块、无重复移动、守恒与休眠唤醒；蒸汽到期与旧事件失效；燃烧传播/灭火/燃尽；混合结构/跨块断开；旋转覆盖与恢复；命令拒绝、Faulted/Reset及显示版本。

Windows Player当前约4万格p95≤4ms/p99≤8ms；百万格/十万活动p95≤10ms/p99≤16ms；集中拆分峰值≤50ms。预热1000Tick，采样10000Tick；集中/分散、水/汽/火/混合分别测。普通稳态Tick与显示准备GC Alloc=0。1920×1080显示单测p95≤4ms。未达标如实记录并继续优化，不减少材料或降低Tick频率掩盖。
